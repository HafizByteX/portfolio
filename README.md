# 👨‍💻 Personal Portfolio Website

Hi there, I'm Abdulhafiz! 👋  
This is my personal portfolio website designed to showcase my skills, projects, and background as a software engineering student.

---

## 🧾 About the Project

A clean, responsive personal portfolio built using HTML, CSS, and JavaScript. It presents a well-structured overview of who I am, the technologies I use, and the projects I've worked on.

The goal is to have a simple yet elegant online presence that reflects my passion for development and gives potential collaborators, clients, or employers an easy way to learn about me.

---

## 💡 Key Features

- 🏠 **Home** – Brief intro and welcome  
- 🙋‍♂️ **About Me** – Education background, interests, and goals  
- 🧠 **Tech Stack** – Highlights frontend skills  
- 🛠️ **Projects** – Real-world project showcases with details  
- 📞 **Contact** – Simple and clear contact section  
- 📱 **Responsive Design** – Fully optimized for mobile, tablet, and desktop  

---

## 🔧 Tech Stack

### Frontend
- HTML5  
- CSS3  
- JavaScript  

### Design & Animations
- Custom CSS animations  
- Smooth scroll and interactive elements with vanilla JavaScript  

---

## 📌 Challenges & Solutions

**Challenge:** Creating smooth scroll and interactive project sections without using frameworks.  
**Solution:** Leveraged vanilla JavaScript and basic DOM manipulation for smooth transitions and responsiveness.

**Challenge:** Designing a modern, responsive layout across all devices.  
**Solution:** Used Flexbox and media queries to ensure consistent performance on all screen sizes.
